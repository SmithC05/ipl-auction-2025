# 📌 About The Project

The **IPL 2025 Auction Simulator** recreates the excitement of a real IPL player auction.

Users can manage teams, bid for players, and build the strongest squad using smart strategies.
The system evaluates teams using a **Team Strength Score**, helping determine the best lineup after the auction.

Designed to be **fast, mobile-first, and lightweight**, the platform even works on extremely **low bandwidth networks**.

# 🚀 Features

| Feature                     | Description                        |
| --------------------------- | ---------------------------------- |
| 🏏 **Real IPL Teams**       | Manage up to **10 IPL teams**      |

| 📱 **Mobile First UI**      | Optimized for mobile devices       |

| 🌐 **Offline Capable**      | Works on extremely low bandwidth   |
